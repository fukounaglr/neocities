Shimejis

Shimejis are little desktop pets that wander around your screen and interact with your windows.

Shimeji base [kilkakon.com]

Assymetrical shimejji [mod by me]
How to install
Desktop

step 1. install Java

step 2. download Zip by clicking on the link
(the download will start automatically)

step 3. Unpack the Zip file in location of choice

done! now you can start the software by double-clicking the [shimeji name].jar file!

Mobile

to install shimeji on mobile, you need to unpack the Zip file and pick the files of "img" folder, following this tutorial:

how to install SHimeji on mobile
How to enable / disable clones

step 1. go to "conf" folder

step 2. open file "settings.properties" in notepad

step 3. in line 6, set "Breeding=true" or "Breeding=false" to enable or disable duptication of shimejis
